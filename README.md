### 10-Lesson Amazon DocumentDB Course

| Lesson | Topic                              | What you'll master                                                          |
| ------ | ---------------------------------- | --------------------------------------------------------------------------- |
| **1**  | 🧱 DocumentDB Fundamentals         | Architecture, concepts, terminology, MongoDB compatibility                  |
| **2**  | 📄 Documents, Collections & BSON   | Documents, collections, BSON, data types, nested data                       |
| **3**  | ✏️ CRUD Operations                 | Insert, read, update, delete documents                                      |
| **4**  | 🔎 Queries & Operators             | Filters, comparison, logical, array, nested-field queries                   |
| **5**  | ⚡ Indexes & Query Performance      | Index types, compound indexes, explain plans, optimization                  |
| **6**  | 🏗️ Data Modeling                  | Embedding, referencing, schema design, access patterns                      |
| **7**  | ☁️ DocumentDB Architecture on AWS  | Clusters, instances, replicas, storage, endpoints, failover                 |
| **8**  | 🔐 Security & Networking           | VPC, subnets, security groups, TLS, encryption, authentication              |
| **9**  | 💾 Backup, Monitoring & Operations | Snapshots, backups, recovery, CloudWatch, scaling, maintenance              |
| **10** | 🚀 Production Project              | Build, secure, optimize, monitor, and troubleshoot a real DocumentDB system |

### How we'll learn

Every lesson will have:

**1. Concept** → understand *what it is*

**2. Why it matters** → understand *why AWS uses it*

**3. Architecture** → visualize *how it works*

**4. Commands / code** → actually use it

**5. Real-world example** → see where it fits

**6. Hands-on exercise** → practice it

**7. Interview questions** → prepare for interviews

**8. Mini quiz** → verify you understood it

   * What Amazon DocumentDB is
   * Document databases vs relational databases
   * MongoDB compatibility
   * Clusters, instances, and collections
